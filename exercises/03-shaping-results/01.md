# 03.01 — Sci-fi titles and prices

**Collection:** `products` · **Concepts:** `projection` · **Order matters:** no

## Task

For every `"sci-fi"` product return **only** the `title` and `price` fields — and no `_id`.

**Write your answer in:** [`answers/03-shaping-results/01.js`](../../answers/03-shaping-results/01.js)
**Check it:** `npm run check -- 03-shaping-results/01` · **See your output:** `npm run try -- 03-shaping-results/01`

**Self-check:** you should get **13** results.

<details>
<summary>💡 Hint (try without it first)</summary>

The second argument of `find()` is an *options* object. Choose fields with its `projection` option: `{ projection: { field: 1 } }` includes a field. `_id` is included unless you set `_id: 0`.

(In mongosh you'd write the projection directly as the second argument. The Node driver would silently ignore that.)
