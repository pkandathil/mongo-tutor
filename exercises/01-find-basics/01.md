<details>
<summary>💡 Hint (try without it first)</summary>

`find()` takes a *filter document*: `{ field: value }` matches documents where that field equals that value.

`find()` gives you a **cursor**, not the documents themselves. Turn it into an array with `.toArray()`, which is what you'd do in app code too.
