# 02.08 — null vs missing

**Collection:** `customers` · **Concepts:** `$type`, `null`, `missing-fields` · **Order matters:** no

## Task

The `referredBy` field comes in three flavours: it holds a customer id, it is **explicitly set to `null`**, or it is **missing entirely**.

Find only the customers where `referredBy` **exists and is `null`**.

First try `{ referredBy: null }` as the filter (e.g. in [`playground/scratch.js`](../../playground/scratch.js)) and count the results — then work out why that is *not* the answer.

**Check it:** `npm run check -- 02-query-operators/08` · **See your output:** `npm run try -- 02-query-operators/08`
